# Dashboard 1.4.0 — cat avatar, image destination and clock

- Default/fallback avatar now embeds the supplied cat.jpg unchanged (1350×1350).
- Avatar uploads are copied into .obsidian/plugins/dashboard/images, derived
  from the actual plugin directory for custom config directories.
- Startup copies a selected legacy sibling image into the new directory and
  persists the new path. It retains originals; copy/read failures keep the old
  setting and show a Notice without blocking startup. Legacy paths can still
  resolve if migration fails. No unrelated image is moved or deleted.
- Weekday/date/year align right. Local time HH:mm appears below the date and
  uses the shared clock check every 30 seconds and on leaf changes. Midnight
  still advances the tracker, preserving historical selections.

Validation: reproduced old destination failures before the fix; build, syntax
check and all 50 Node behavior tests pass (14 avatar, 28 integration, 8 model).
Firefox DOM/interaction checks pass in both themes at 1440/700/390/280px and a
narrow pane inside a wide window. Verified clock updates, original palettes,
file picker/import destination, reset to decoded cat JPEG, search/IME, custom
rules, multiple embeds and cleanup. No screenshots or real-vault writes.
Obsidian host APIs are simulated; no live Obsidian installation was tested.
