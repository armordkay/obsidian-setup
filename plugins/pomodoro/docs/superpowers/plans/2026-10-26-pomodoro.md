# Pomodoro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Plugin Pomodoro chạy cục bộ, dùng giao diện v13 đã duyệt trong tab và note.

**Architecture:** Một Timer thuần quản lý trạng thái và deadline. Plugin sở hữu timer,
interval và queue lưu; MarkdownRenderChild hiển thị cùng trạng thái trong mọi view.
Giữ một main.js như plugin Eisenhower để cài trực tiếp, không build.

**Tech Stack:** JavaScript CommonJS, Obsidian API, SVG/CSS, node:test.

**Spec:** `../specs/2026-10-26-pomodoro-design.md`

## Global Constraints

- Plugin ID `pomodoro`, phiên bản 1.0.0, Obsidian >=1.5.0; hỗ trợ desktop/mobile.
- Không thêm runtime dependency, package manager hoặc bước build.
- Mặc định học 25, nghỉ 5 phút; mỗi thời lượng là số nguyên 1..180 phút.
- Nét ẩn opacity 0.045; tiếng Việt, theme từ Obsidian, không gọi mạng.
- Không commit/push/deploy; không sửa hai plugin tham khảo hoặc công việc có sẵn.

## Review Focus

- Callback bị trễ/ngủ máy: thời gian nghỉ bắt đầu từ deadline học (Task 1).
- Pause sát deadline: chuyển pha trước khi áp dụng thao tác (Task 1).
- Restart/dữ liệu hỏng: restore hợp lệ hoặc fallback an toàn (Task 1).
- Nhiều view và đóng view: timer dùng chung, unsubscribe khi unload (Task 2).
- Ghi dữ liệu lỗi/đang chờ: queue tuần tự và retry snapshot mới nhất (Task 2).

## Files

- `main.js`: Timer, renderer, view và plugin lifecycle; CommonJS entry độc lập.
- `styles.css`: CSS scoped từ v13, theme Obsidian và container responsive.
- `manifest.json`: metadata để Obsidian nạp plugin.
- `tests/main.test.cjs`: fake clock và host tests, không dependency.
- `tests/preview.html`: browser smoke host chạy main.js/styles.css thật.
- `README.md`: cài đặt, sử dụng, hành vi, lệnh kiểm chứng và giới hạn.
